01 / QUOTA

你的额度模式，它自己看懂。

只有周额度，就只显示周额度；恢复“五小时 + 周额度”，界面自动变成双窗口。百分比、窗口长度和重置时间均来自当前 Codex 账号。

REAL
只读取 Codex 主额度快照，不把 gpt-reserve 等其他产品窗口混进周额度，也不把 Token 换算成虚假百分比。
02 / CONTINUITY

额度重置，
长任务接着推进。

高效使用 Codex，从少一次等待开始。开启自动续聊后，5 小时窗口重置再过 3 分钟，因额度不足中断的长任务会在原对话继续，保留原模型与推理强度。没有待续任务时，自动发送“你好”，让新一轮工作更快开始。

OPT-IN
默认关闭，可随时停用。Mac 与 CodexBar 需保持运行；周额度仍不足时等待，已由你继续的任务不重复发送。
03 / NOTIFICATIONS

周额度恢复，
钉钉告诉你。

不用反复打开面板确认。配置钉钉机器人 Webhook 与通知关键字，先发送测试，再接收周额度重置提醒。自然轮换或可识别的提前重置，都能在你配置的钉钉会话里看到。

CONFIGURE
仅提醒周额度，5 小时额度不通知。Webhook 保存在本机钥匙串，同一次重置不会反复提醒。
04 / MODELS

模型随任务选，
管理在一处。

在 CodexBar 管理 OpenAI 与 DeepSeek 来源、API Key 和实时余额。进入 DeepSeek 后，Flash 与 V4 Pro 直接在 Codex 原生模型菜单选择，无需为每次换模型重启。任务卡也会显示具体模型，方便找到对应工作。

RESTORE
切换 OpenAI 与 DeepSeek 来源时，先确认重启影响；跨来源历史任务回到原对话。模型与来源不匹配时，面板提供检测与修复入口。
05 / TASKS

所有进行中工作，回到同一处。

普通运行任务与 active Goal 合并统计，同一线程自动去重。点击任意任务，通过 Codex 深链返回对应窗口；刷新和跳转都不会让运行时间重新计数。

LINK
任务数量、标题、项目、状态和计时，围绕“马上找到并继续工作”组织。
06 / GUARDRAIL

给每个任务，一条清晰边界。

任务行内即可设置 25K–5M Token 上限。达到 90% 自动提示 Codex 收尾；触达上限只停止对应 turn，不影响其他任务和整个桌面应用。

CONTROL
真实 Token 从设置上限时开始累计；限额百分比只表示任务对自定义预算的占用。
07 / RESET CREDIT

记住到期日，也替你守住最后一小时。

主面板只保留数量、到期日和自动使用开关，任务列表不会被卡片明细挤走。点击摘要后，二级浮层才展示逐卡状态与下一次动作。

OPT-IN
自动使用默认关闭；开启后到期前一小时优先使用最早到期卡，并以幂等记录避免重复兑换。
Designed for continuity

安静地运行。需要时，准确地出现。

CodexBar 是原生 macOS 工具，不要求你迁移工作流。它跟随 Codex Desktop 启动，也允许你独立关闭。

01

模型配置与恢复

统一配置 DeepSeek Key、验证可用模型并查看实时余额。Flash 与 Pro 在 Codex 原生菜单选择；退出或异常恢复时还原原 Codex 配置。

02

稳定刷新

额度通常每 60 秒、任务每 15 秒刷新；打开面板立即重试。短暂失败时保留明确标注的成功缓存，按退避节奏恢复获取。

03

真实计时

任务秒数取自当前 turn 的真实启动时间。点击跳转、关闭面板、再次打开或主动刷新，都不会改变这段时间。

04

自动伴随启动

Codex Desktop 开启时自动补启动 CodexBar；登录后也可自动运行。两者关闭互不影响，不会生成重复实例。

05

精准停止

通过 Codex 官方 app-server 控制通道中断具体 thread 与 turn，不使用 kill 结束整个 Codex，也不连带影响其他任务。

06

自适应账号与模型标识

自动使用当前 macOS 用户的 Codex 登录态和 CODEX_HOME，并兼容 OpenAI 当前的原生 Provider 标识，任务不会误显示为未知模型。

07

菜单栏自适应摘要

自动适配单窗口与双窗口额度，展示任务数与重置时间；并排显示上传、下载实时速度，固定宽度减少菜单栏跳动。
